# Trades POC 1

Minimal Vercel-hosted IBKR execution-layer proof of concept.

## Current version
- Static web UI
- `/api/ibkr-test` endpoint
- No order submission
- No IBKR credentials stored in source

## Deployment
Push these files to the `main` branch of `xavwen999/Trades_poc1`.
Vercel should automatically create a deployment if the project is linked to the repository.

## Next step
Configure the appropriate IBKR API architecture and credentials as Vercel environment variables. Do not commit credentials to GitHub.
